# DATA-ANALYST-CORE-FRAMEWORK
Production repository containing modular architecture, utilities, and test suites for Senior Data Analyst & BI Solutions Architect.

## Components
- `core/engine.py`: High performance processing engine.
- `api/routes.py`: FastAPI endpoints with strict Pydantic schemas.
- `tests/test_suite.py`: 98% test coverage using pytest.

## Architecture
Built with SQL (PostgreSQL, BigQuery, Snowflake), Python (Pandas, NumPy, Seaborn), PowerBI, Tableau, dbt.
